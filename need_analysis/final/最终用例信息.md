## UC-01 查询单词/短语

- **用例名**：查询单词/短语
- **用例标识**：UC-01
- **主要执行者**：学习者
- **目标**：输入日文单词、短语或短句，检索剧情中使用该表达的台词，作为学习该表达的例句。
- **范围**：覆盖 FR-1（模糊查询）、FR-2（活用形扩展）、FR-3（读音归一化/表記ゆれ）、FR-13（容错级别）、FR-15（无结果处理）。
- **前置条件**：软件已启动，剧情数据与索引加载完成（UC-11 通过）；输入非空、不全为通配符、长度 ≤ 100 字符。
- **交互动作**：
  1. 学习者在搜索框输入日文单词/短语/短句并提交查询；
  2. 系统校验输入（非空、不全为通配符、≤ 100 字符），无效则明确提示；
  3. 系统按设置的容错级别执行匹配：子串（包含式）匹配 + 活用形扩展 + 双向读音归一化（同音异义词全量命中仅在中/强容错级别生效）；
  4. 系统返回命中列表：按当前排序规则（默认相关度）分页展示（默认 50 条/页），命中部分高亮；
  5. 结果总数超过 1000 条时显示「结果过多，建议筛选」提醒，用户仍可翻页浏览；无命中时提示「未找到」并显示查询建议（改用基本形、放宽通配符、调整容错级别）。
- **后置条件**：有命中时显示结果列表；无命中时显示空态与建议。
- **异常流程**：
  1. 本地无剧情数据 → 提示「请先更新剧情数据」；
  2. 空输入 / 纯通配符 / 超 100 字符 → 明确提示输入无效。

## UC-02 语法模式查询（通配符）

- **用例名**：语法模式查询（通配符）
- **用例标识**：UC-02
- **主要执行者**：学习者
- **目标**：输入含通配符的语法模式（如「〜を〜にして」），查询剧情中符合该模式的台词。
- **范围**：覆盖 FR-4（语法模式查询）；固定部分的匹配沿用 FR-2、FR-3。
- **前置条件**：软件已启动，剧情数据与索引加载完成；输入中含至少一个非通配符字符。
- **交互动作**：
  1. 学习者在搜索框输入含通配符的模式（默认「〜」，可在设置中更改），搜索界面提供占位说明或示例提示；
  2. 系统校验输入，全部为通配符时提示输入无效；
  3. 系统执行匹配：每处通配符在单句台词内匹配任意长度（含 0 字）的内容，固定部分同样适用活用形扩展与读音归一化；
  4. 系统返回命中列表（筛选、排序、分页同 UC-01）；无命中时提示「未找到」并显示建议（减少固定部分、检查通配符符号）。
- **后置条件**：固定部分全部命中的台词以列表形式返回；无命中时显示空态与建议。
- **异常流程**：
  1. 本地无剧情数据 → 提示「请先更新剧情数据」；
  2. 输入全部为通配符 → 明确提示输入无效。

## UC-03 筛选查询结果

- **用例名**：筛选查询结果
- **用例标识**：UC-03
- **主要执行者**：学习者
- **目标**：按剧情类型、团体、角色、时间缩小结果范围，快速定位目标例句。
- **范围**：覆盖 FR-6（结果筛选）。
- **前置条件**：已有查询结果（完成 UC-01 或 UC-02）；或搜索前预设场景（本地已有剧情数据）。
- **交互动作**：
  1. 学习者设置筛选条件，各维度可组合：剧情类型（主线 / 活动 / 卡面前篇·后篇 / 区域对话 / 虚拟演唱会台词 / 生日·纪念）、团体（Leo/need、MORE MORE JUMP!、Vivid BAD SQUAD、Wonderlands×Showtime、25時、ナイトコードで。、Virtual Singer）、角色、时间（日历日期范围 或 活动列表，两种方式）；
  2. 系统按筛选条件即时过滤当前结果列表（或对搜索前预设的条件在搜索时生效）；
  3. 系统展示符合全部筛选条件的条目；无符合项时显示「未找到符合条件的结果」；
  4. 学习者可一键清除筛选，系统恢复原列表。
- **后置条件**：结果列表缩小为符合全部筛选条件的条目。
- **异常流程**：无。

## UC-04 排序与分页浏览结果

- **用例名**：排序与分页浏览结果
- **用例标识**：UC-04
- **主要执行者**：学习者
- **目标**：以指定顺序和每页条数浏览查询结果。
- **范围**：覆盖 FR-7（结果排序）、FR-8（分页与结果量控制）。
- **前置条件**：已有查询结果（完成 UC-01 或 UC-02）。
- **交互动作**：
  1. 学习者选择排序标准（相关度[默认] / 剧情实装时间，各支持升/降序）；
  2. 系统按相关度打分规则重排：书写形式完全命中 > 活用变形/派生命中 > 读音归一化命中 > 通配分隔命中；其次按固定部分覆盖率、同句命中次数；同分按实装时间；
  3. 学习者设置每页条数（默认 50）并翻页浏览；
  4. 系统按所选顺序分页展示；超过 1000 条时显示「结果过多，建议筛选」提醒（仍可浏览）。
- **后置条件**：结果按选定标准重新排列并分页展示。
- **异常流程**：无。

## UC-05 查看例句详情

- **用例名**：查看例句详情
- **用例标识**：UC-05
- **主要执行者**：学习者
- **目标**：查看选中例句的完整台词、角色、出处、译文、注音及前后文上下文。
- **范围**：覆盖 FR-5（结果展示）、FR-11（假名注音显示）。
- **前置条件**：存在结果列表且至少有一条命中。
- **交互动作**：
  1. 学习者从结果列表点击/展开一条例句；
  2. 系统展示该例句详情：完整台词原文（命中高亮）、说话角色、出处（剧情类型 + 剧情/活动名称 + 话数/章节 + 台词序号）、国服译文（有对应译文时显示，否则显示「暂无翻译」）、假名注音（设置中开启时显示）；
  3. 学习者可展开查看该台词前后几句对话；
  4. 系统显示上下文对话内容。
- **后置条件**：展示所选例句的完整信息与上下文。
- **异常流程**：无。

- **异常流程**：无。

## UC-07 收藏例句

- **用例名**：收藏例句
- **用例标识**：UC-07
- **主要执行者**：学习者
- **目标**：将选中例句（连同出处与上下文）存入本地收藏，供日后查看；可取消收藏。
- **范围**：覆盖 FR-10（收藏）。
- **前置条件**：存在结果列表且选中一条例句；本地存储可写。
- **交互动作**：
  1. 学习者对选中例句执行收藏操作；
  2. 系统将例句连同出处与上下文信息写入本地收藏；重复收藏时不产生重复条目，提示已收藏或直接取消收藏；
  3. 系统在界面上显示该例句的收藏状态；
  4. 学习者可对已收藏例句取消收藏，系统将其移出收藏并更新状态。
- **后置条件**：例句存入或移出收藏，收藏状态在界面上可辨识，收藏列表（UC-08）同步更新。
- **异常流程**：
  1. 重复收藏同一条例句 → 提示已收藏或直接取消收藏，不产生重复条目。

## UC-09 个性化设置

- **用例名**：个性化设置
- **用例标识**：UC-09
- **主要执行者**：学习者
- **目标**：按个人偏好调整匹配容错级别、排序、注音、通配符符号、复制内容、每页条数等设置。
- **范围**：覆盖 FR-13（个性化设置）；设置项影响 FR-3、FR-4、FR-7、FR-8、FR-9、FR-11。
- **前置条件**：软件已启动。
- **交互动作**：
  1. 学习者打开设置界面，调整各项：匹配容错级别（弱[默认]/中/强；中级别含同音异义词全量命中与轻微书写差异容忍，强级别另含相近词条互通与编辑距离近似匹配）、默认排序规则、注音显示开关、通配符默认符号（默认「〜」）、复制内容选项、每页条数（默认 50）；
  2. 系统保存设置并即时生效；
  3. 后续查询与展示行为按新设置执行。
- **后置条件**：设置持久化保存并即时生效。
- **异常流程**：无。

## UC-10 更新剧情数据

- **用例名**：更新剧情数据
- **用例标识**：UC-10
- **主要执行者**：数据维护者
- **目标**：通过三种途径将本地剧情数据更新到最新版本并重建索引。
- **范围**：覆盖 FR-12（剧情数据更新）。
- **前置条件**：途径 ①（一键更新）需网络可用、目标仓库地址可达；途径 ②（手动文件）需数据文件符合软件约定格式。
- **交互动作**：
  1. 数据维护者选择更新途径：① 点击软件内「一键更新」按钮；② 将符合格式的数据文件放入软件数据目录；③ 随软件版本升级获得内置新数据；
  2. 系统下载/检测/装载数据，并校验数据格式与完整性；
  3. 校验通过后系统重建索引，更新完成后可查询到最新剧情；
  4. 更新失败时系统保留旧数据与索引并提示失败原因，可重试。
- **后置条件**：更新成功时本地数据更新为最新版本、索引重建完成；失败时旧数据与索引保持可用。
- **异常流程**：
  1. 网络中断或仓库不可达 → 提示「更新失败」及原因，保留旧数据，可重试；
  2. 数据文件格式不符或损坏 → 拒绝导入并提示，保留旧数据。

## UC-11 启动与数据校验

- **用例名**：启动与数据校验
- **用例标识**：UC-11
- **主要执行者**：学习者
- **目标**：启动软件并确保剧情数据与索引完整可用，进入可查询状态。
- **范围**：覆盖 FR-14（启动与数据校验）。
- **前置条件**：用户启动软件。
- **交互动作**：
  1. 学习者启动软件；
  2. 系统校验剧情数据与索引的完整性；首次启动加载数据时显示进度；
  3. 数据正常时系统进入可查询状态；
  4. 数据缺失或损坏时系统显示引导界面，提示并引导通过 UC-10 更新；数据恢复前查询功能不可用。
- **后置条件**：数据正常时进入可查询状态；数据异常时停留在引导界面。
- **异常流程**：
  1. 数据文件缺失/损坏 → 启动提示并引导更新，更新完成前查询功能不可用。
