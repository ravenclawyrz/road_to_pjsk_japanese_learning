## 用例综述
共 10 个用例。UC-1 ～ UC-8 以学习者为主要参与者，UC-9 以数据维护者为主要参与者，UC-10 为系统启动用例。UC-1/UC-2 为查询核心，UC-3 ～ UC-5 操作查询结果，UC-6 ～ UC-8 为学习辅助与偏好，UC-9/UC-10 保障数据可用性。Anki 导出为后续扩展（优先级高于中文反查），不在本期用例范围。

---

### UC-1 关键词查询例句
- **参与者**：学习者
- **描述**：学习者输入日文单词、短语或短句（不含分隔符的普通查询），软件在剧情库中执行模糊查询（子串匹配 + 活用形扩展 + 读音归一化，容错级别按用户设置），返回所有匹配台词。
- **前置条件**：软件已启动，剧情数据与索引加载完成；输入非空、不全为分隔符、长度 ≤ 100 字符。
- **后置条件**：有命中时显示结果列表（命中高亮、按当前排序规则排列），命中超过 1000 条时提示细化查询；无命中时显示空态与查询建议（如改用基本形、放宽分隔符、调整容错级别）。

### UC-2 分隔（通配）查询
- **参与者**：学习者
- **描述**：学习者输入含分隔符的语法条目模式（如「……を……にして」），分隔符为设置中指定的符号（……、＊、※ 等）。每处分隔符在单句台词内匹配任意长度（含 0 字）的内容；模式中固定部分同样适用活用形扩展与读音归一化。
- **前置条件**：软件已启动，剧情数据与索引加载完成；输入中含至少一个非分隔符字符。
- **后置条件**：固定部分全部命中的台词以列表形式返回；无命中时显示空态与建议（如减少固定部分、检查分隔符符号）。

### UC-3 查看例句详情
- **参与者**：学习者
- **描述**：学习者从结果列表选择一条例句，查看其完整台词原文、说话角色、出处（剧情类型 + 剧情/活动名称 + 话数/章节 + 台词序号）、国服译文（有对应译文时显示，否则留空）、假名注音（开启时显示），并可展开查看该台词前后几句对话。
- **前置条件**：存在结果列表且至少有一条命中。
- **后置条件**：展示所选例句的完整信息与上下文；信息不全（如无译文）时按 FR-5 约定留空显示。

### UC-4 筛选搜索结果
- **参与者**：学习者
- **描述**：学习者按剧情类型（主线 / 活动 / 卡面前篇·后篇 / 区域对话 / 生日·纪念）、团体（Leo/need、MORE MORE JUMP!、Vivid BAD SQUAD、Wonderlands×Showtime、25時、ナイトコードで。、Virtual Singer）、角色对当前结果进行筛选，各维度可组合使用。
- **前置条件**：存在结果列表。
- **后置条件**：列表仅显示符合筛选条件的条目；无符合项时显示空态，可一键清除筛选恢复原列表。

### UC-5 排序搜索结果
- **参与者**：学习者
- **描述**：学习者将结果按相关度（默认）或剧情实装时间（活动/章节发布顺序）排序，各支持升/降序。相关度打分：书写形式完全命中 > 活用变形命中 > 读音归一化命中 > 通配分隔命中；其次按查询表达式覆盖率、同句命中次数；同分按实装时间。
- **前置条件**：存在结果列表。
- **后置条件**：列表按所选排序规则重新排列。

### UC-6 复制例句
- **参与者**：学习者
- **描述**：学习者将选中例句复制到剪贴板，内容为台词原文 + 说话角色 + 出处；是否附带译文/注音按个性化设置决定。
- **前置条件**：存在结果列表且选中一条例句。
- **后置条件**：剪贴板包含例句文本，界面提示复制成功。

### UC-7 收藏例句
- **参与者**：学习者
- **描述**：学习者将选中例句加入收藏，并可在收藏界面查看收藏列表、移除已收藏条目。
- **前置条件**：收藏时需存在结果列表且选中一条；查看/移除时需已有收藏记录。
- **后置条件**：例句存入或移出收藏，收藏状态在界面上可辨识。

### UC-8 个性化设置
- **参与者**：学习者
- **描述**：学习者调整匹配容错级别（弱/中/强，默认弱；强级别含相近词条互通与拼写纠错）、默认排序规则、注音显示开关、分隔符默认符号、复制内容选项等。
- **前置条件**：软件已启动。
- **后置条件**：设置持久化保存并即时生效，影响后续查询与展示行为。

### UC-9 更新剧情数据
- **参与者**：数据维护者
- **描述**：通过三种途径更新剧情数据并重建索引：① 一键更新——联网从指定 GitHub 开源仓库拉取最新数据（用户手动触发）；② 手动将符合格式的数据文件放入软件数据目录，软件检测后提示重建索引；③ 随软件版本升级获得内置新数据。更新前校验数据格式与完整性。
- **前置条件**：途径 ① 需网络可用；途径 ② 需数据文件符合软件约定格式。
- **后置条件**：更新成功时索引重建完成，可查询到最新剧情；失败时旧数据与索引保持可用，并提示失败原因。

### UC-10 启动与数据校验
- **参与者**：学习者
- **描述**：软件启动时校验剧情数据与索引的完整性；数据缺失或损坏时提示并引导通过 UC-10 修复；首次启动加载数据时显示进度。
- **前置条件**：用户启动软件。
- **后置条件**：数据正常时进入可查询状态；数据异常时显示引导界面，不进入查询。
